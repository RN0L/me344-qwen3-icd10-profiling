# Same JAX version as the TPU and CPU rows. jaxlib, jax-cuda12-pjrt and jax-cuda12-plugin all
# publish cp312 manylinux_2_27_aarch64 wheels at 0.10.2 (verified against PyPI), which is what
# makes "identical framework across three backends" true rather than aspirational.
#
# cuda12, not cuda13: the CUDA 12 wheel family is the one with a complete aarch64 matrix, and
# CUDA 12.x minor-version compatibility means these userspace libs run against any >=525 driver,
# so we do not need to know the GKE node's exact driver build in advance.
